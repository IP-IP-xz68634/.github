<h2>一、一站式服务通常包含什么</h2>
<p>常见的一站式包含三段：分配IP与带宽、给你接入凭据、协助把地址配到你的设备上。第三段各家差别最大。</p>
<p>有的只发一份文档让你自己看，有的可以远程协助配一次。买之前问清协助是几次、多久内有效。</p>
<p>如果对方连工单渠道都没有，所谓一站式基本只剩卖IP，后面排错全靠自己。</p>
<h3>别把一站式当成全包</h3>
<p>账号环境、指纹浏览器、自动化脚本这些通常不在服务范围内，需要你另行准备，别默认对方会一并配好。</p>
<h2>二、下单时要提交哪些信息</h2>
<p>一般要提交用途说明、接入地区、需要的IP数量、预计并发设备数。部分商家还会要求身份信息做登记。</p>
<p>接入方式要提前说：是给HTTP代理端口，还是给静态地址加网关。两种交付物完全不同，临时改要重新配置。</p>
<p>如果设备在机房，最好提供机柜位置和上联运营商，方便对方判断线路走向和延迟水平。</p>

<h2>三、静态地址的三种落地形态</h2>
<p>第一种是直接在主服务器网卡上再加一个地址，适合单机业务。第二种走策略路由，按目标分流。第三种整段交给路由器。</p>
<p>单机加地址最省事，但一台机器只能有一套出口。策略路由灵活，配置复杂度也最高。</p>
<p>整段交给路由器适合多设备共享，代价是多一层NAT，端口映射要另外规划。</p>

<h2>四、服务器侧的配置步骤</h2>
<p>先备份原配置，再动手。改之前把当前路由和DNS导出一份，出问题能快速回滚。</p>
<p>Linux 下常见做法是给网卡加一个别名地址，再单独写一条默认路由。命令写完先用ip addr确认生效。</p>
<p>DNS 不要沿用机房默认值。用目标地区附近的解析服务，能减少一部分跨区解析带来的延迟。</p>
<h3>双地址的写法</h3>
<p>同一网卡挂两个地址时，只给主地址配默认网关。第二条路由用metric调优先级，避免出现回包走错出口。</p>
<h2>五、路由器侧的接入配置</h2>
<p>把服务商给的地址填到WAN口，掩码和网关照抄，不要自己推算。填错一位就整段不通。</p>
<p>内网侧建议单独划一个网段，和家里原有网络隔开。这样出问题时影响范围可控，排查也清晰。</p>
<p>需要外网访问内网设备时，用端口映射而不是全开DMZ。映射规则越少，暴露面越小。</p>
<h2>六、验收清单和日常维护</h2>
<p>验收跑四项：ping网关、解析域名、测上下行速度、看公网出口地址是否为目标地址。四项都过再交付业务。</p>
<p>上线后第一周每天记录一次延迟和丢包，形成基线。后面出现波动时才有对比依据。</p>
<h3>一周观察期</h3>
<p>线路刚开通时的表现不代表长期水平。跨洋线路在本地晚高峰会有明显变化，观察满一周再判断。</p>
<h2>常见问答</h2>
<h3>一站式服务能不能帮我把账号环境也配好？</h3>
<p>答：多数只负责网络层。账号环境涉及浏览器、指纹和操作习惯，通常要自己搭，购买前问清服务边界即可。</p>
<h3>静态地址可以直接配在笔记本上吗？</h3>
<p>答：可以，但要注意所在网络不能有相同网段，否则会冲突。多数人更愿意把地址放在路由器上，笔记本走内网。</p>
<h3>服务商给的DNS必须用吗？</h3>
<p>答：不必须。DNS可以自行指定，只要解析正常即可。跨区业务建议选目标地区附近的解析服务。</p>
<h3>配置完成后速度慢是哪里出了问题？</h3>
<p>答：先分段测：本机到网关、网关到出口、出口到目标站点。定位到哪一段再处理，比直接换服务商有效。</p>
